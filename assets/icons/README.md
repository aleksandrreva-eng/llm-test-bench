# Иконки приложения

Два набора, оба — дизайн-исходники. Приложение их напрямую не использует: значки
в интерфейсе рисует `llmtestbench/ui/icons.py` на QPainter (19 токенов, без
файлов). Из векторов собирается только то, что перечислено ниже.

## Набор 1 — текущая иконка (29.09.2026)

| файл | что это |
|---|---|
| `app-icon.svg` | **источник `icon.ico`**: изометрический куб GGUF-модели на тёмной плитке. Галочка — пройденные тесты, восходящие столбики — замеры производительности |
| `app-icon-mark.svg` | тот же знак **без подложки** — для кадров ролика, README и светлых фонов |
| `app-icon-mark.png` | знак без подложки, растром: обрезан по контуру с полем 4 %, собран `make_icon.py` |
| `preview.html` | лист проверки: знак на тёмной плитке и без неё, на тёмном и светлом фоне, в интерфейсе. Самодостаточный — SVG вшиты в data-URI |

Плитка в `app-icon.svg` — скруглённый квадрат 512×512 (радиус 112), внутри
вертикальный градиент и синее свечение; куб нарисован по центру с запасом под
плитку. Именно поэтому знак **нельзя** брать как есть для мелких размеров без
плитки: он занимает меньше половины квадрата. Отсюда отдельный `app-icon-mark.png`
с обрезкой.

## Набор 2 — изометрические карточки (24.09.2026)

| файл | что нарисовано |
|---|---|
| `История.svg` | стопка дисков с нумерацией 1-2-3 |
| `Модель.svg` | куб с надписью **GGUF** |
| `Отчёт.svg` | куб с гистограммой |
| `Сервер.svg` | куб с лампочками-индикаторами |
| `Тесты.svg` | штамп с двумя галочками |
| `app-icon-gguf-cube.svg` | куб «GGUF» без подписи вкладки — из него короткое время собирался `icon.ico` |

Пять карточек — 240×320, изометрия из трёх граней (`faceTop` / `faceLeft` /
`faceRight`), свечение через `feGaussianBlur`, внизу подпись вкладки отдельным
`<text y="105">`. Это дизайн-исходники, в сборку они не попадают.

## Сборка

```
.venv\Scripts\python.exe make_icon.py
```

Собирает сразу два файла: корневой `icon.ico` и `app-icon-mark.png`. Кадры 16, 24,
32, 48, 64, 128, 256, каждый **отрисовывается вектором отдельно**, а не уменьшается
из одного большого растра — на 16×16 разница видна глазом. Кадры пишутся несжатым
BMP, а не PNG: PNG-кадры внутри ICO не понимает WiX, который собирает MSI и берёт
`..\icon.ico` для значка в «Установка и удаление программ». Отсюда размер 364 КБ.

`icon.ico` нужен четырём потребителям: exe (PyInstaller, `EXE(icon=...)` — от него
зависит значок файла в Проводнике), окно (`bundle_root() / "icon.ico"`), MSI и
кадры ролика (`promo/make_frames.py` берёт `app-icon-mark.png`).
