# Иконки приложения

Изометрический набор, нарисованный для LLM Test Bench 24.09.2026. До этого лежал
только в личной библиотеке (`F:\AI\Icons\SVG\`) — то есть за пределами репозитория,
и в публичную версию не попадал.

## Что здесь

| файл | что нарисовано |
|---|---|
| `История.svg` | стопка дисков с нумерацией 1-2-3 |
| `Модель.svg` | куб с надписью **GGUF** |
| `Отчёт.svg` | куб с гистограммой |
| `Сервер.svg` | куб с лампочками-индикаторами |
| `Тесты.svg` | штамп с двумя галочками |
| `app-icon.svg` | **иконка приложения** — куб «GGUF» без подписи вкладки и без тени-подложки |
| `app-icon-legacy-118x132.ico` | прежний `icon.ico`: единственный кадр 118x132, оставлен для истории |

Пять первых файлов — исходные карточки: 240x320, изометрия из трёх граней
(`faceTop` / `faceLeft` / `faceRight`), свечение через `feGaussianBlur`, внизу
подпись вкладки отдельным `<text y="105">`. Они **не используются приложением
напрямую**: значки в интерфейсе рисует `llmtestbench/ui/icons.py` на QPainter
(19 токенов, без файлов). Это дизайн-исходники.

## Иконка приложения

`app-icon.svg` — это `Модель.svg` минус подпись и минус эллипс-тень, с обрезанной
областью: куб занимает в исходнике `x 68..172, y 100..220`, а `viewBox` выставлен
`52 92 136 136`, то есть с полем ~8 единиц. **Правишь геометрию куба — правь и
`viewBox`**, иначе иконка поедет или обрежется.

Из него собирается корневой `icon.ico`:

```
.venv\Scripts\python.exe make_icon.py
```

Кадры 16, 24, 32, 48, 64, 128, 256. Каждый **отрисовывается вектором отдельно**,
а не уменьшается из одного большого растра — на 16x16 разница видна глазом.
Кадры пишутся несжатым BMP, а не PNG: PNG-кадры внутри ICO не понимает WiX,
который собирает MSI и берёт `..\icon.ico` для значка в «Установка и удаление
программ». Отсюда размер 364 КБ.

`icon.ico` попадает и в exe (PyInstaller, `EXE(icon=...)` — от него зависит значок
файла в Проводнике), и в окно (`bundle_root() / "icon.ico"`), и в MSI, и в кадры
рекламного ролика (`promo/make_frames.py` берёт самый крупный кадр).
