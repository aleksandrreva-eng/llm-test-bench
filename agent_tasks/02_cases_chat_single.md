Придумай шесть новых тест-кейсов для набора chat_single — одиночный вопрос,
один ответ, автоматическая проверка.

Верни ТОЛЬКО JSON-массив из шести объектов. Без markdown-обёртки, без
пояснений, без комментариев.

Поля каждого объекта:

- id — строка вида chat_single_011, chat_single_012 и так далее по порядку;
- name — короткое русское название кейса;
- prompt — задание модели на русском языке;
- expected — объект с полем type и данными проверки;
- params — объект, можно указать max_tokens;
- tags — массив коротких меток латиницей;
- weight — число от одного до двух.

Поле type в expected может быть только одним из этих значений:

- contains_any — объект с полем values (массив строк). Ответ зачтён, если
  содержит хотя бы одну из них.
- contains_all — то же, но должны присутствовать все строки.
- not_contains — объект с полем values. Ответ НЕ должен содержать ни одной.
- exact_match — объект с полем value. Ответ должен совпасть точно.
- regex — объект с полем pattern. Регулярное выражение языка Python.
- json_schema — объект с полем schema (описание JSON Schema).

Правила:

1. Задания формулируй так, чтобы правильный ответ был однозначным. Не бери
   темы, где ответ зависит от мнения или от свежих новостей.
2. Проверка должна засчитывать именно правильный ответ и не засчитывать
   неправильный. Не делай проверку, которая пройдёт при любом ответе.
3. Не используй type со значением llm_judge: судьи в наборе нет.
4. Разные кейсы — разные умения: например формат ответа, честное «не знаю»
   вместо выдумки, следование жёсткому шаблону, отказ от лишних пояснений,
   работа с числами, перевод. Не повторяй одну и ту же проверку шесть раз.
5. В заданиях на формат явно требуй: только ответ, без пояснений и без
   markdown-обёртки.

{
  "id": "chat_single_004",
  "name": "Ответ строго в JSON",
  "prompt": "Верни данные о книге «Мастер и Маргарита» в виде JSON с полями title (строка), author (строка), year (число). Верни ТОЛЬКО валидный JSON без markdown-обёртки и пояснений.",
  "expected": {
    "type": "json_schema",
    "schema": {
      "type": "object",
      "required": ["title", "author", "year"],
      "properties": {
        "title": {"type": "string", "minLength": 3},
        "author": {"type": "string", "minLength": 3},
        "year": {"type": "integer", "minimum": 1900, "maximum": 2100}
      }
    }
  },
  "params": {"max_tokens": 192},
  "tags": ["format", "json"],
  "weight": 1.5
}
